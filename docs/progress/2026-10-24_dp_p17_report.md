## 1. Executive Summary

P17 完成了状态条件示教筛选、独立 LeRobot 数据集导出、root 级划分、一次冻结架构 XYZ9 BC 重训，以及新旧模型在同一 held-out root 上的闭环对照。

结果不支持“状态条件示教已经解决闭环抓取”：

- P16 的 15 条查询轨迹中，5 条 `xminus` 轨迹通过全部数据门槛并被选入；
- 每个 source root 只保留一条，pitch 因约 0.216 rad 边界跳变被排除，xminus_slow 因同 root 相关变体被排除；
- 新数据集为 5 episodes、1505 pre-action frames、5 roots；
- split 为 train 0–2、validation 3、test 4，机械检查无 root 泄漏；
- 新旧模型参数量完全相同，均为 1,861,520；
- 新模型 test teacher-forced XYZ9 RMSE 从旧模型的 0.002936 降至 0.000629；
- held-out root 4 的 Approach step 5–20 wrist error 从 6.49 mm 降至 5.19 mm；
- 但新模型完整闭环为 **0 contact、最大抬升 0.013 mm、0/1 FINAL**；
- 旧 P6 在同一 root 为 contact fraction 0.9147、最大抬升 6.79 mm、0/1 FINAL；
- 新模型在训练 root 0 上同样 0 contact，说明不仅是 held-out 泛化失败；
- 已触发“严重 Approach 遗忘/闭环退化”停止条件，没有继续调参、扩容或训练第二个模型。

结论：**状态条件专家后缀本身物理有效，但当前完整轨迹组织不适合单帧 XYZ9 BC。** 轨迹先执行 10 步 BC 前缀，再回到重新规划的 pregrasp/approach，产生阶段回折和相似状态下的不同动作方向；5 条轨迹的 XYZ9 chunk 又高度近重复。离线误差因此显著下降，却没有转化为闭环接近与接触。

## 3. P17-A：状态条件轨迹筛选

### 3.1 纳入规则

必须同时满足：

1. 完整组合轨迹 `FINAL_VERIFIED`；
2. snapshot qpos/qvel/ctrl/qacc 恢复最大误差 ≤1e-6；
3. IK failure=0、joint-limit violation=0；
4. arm7 边界 L2 jump ≤0.05 rad；
5. hand6 边界 L2 jump ≤0.001 m；
6. 一个 source root 只保留一个相关变体。

### 3.2 审计结果

| P16 plan | 数量 | FINAL | 边界兼容 | P17处理 |
|---|---:|---:|---:|---|
| xminus | 5 | 5/5 | 5/5 | 纳入5条 |
| xminus_slow | 5 | 5/5 | 5/5 | 同root相关变体，仅诊断 |
| pitch | 5 | 5/5 | 0/5 | 边界约0.216 rad，排除 |

选中轨迹的arm7 jump为0.02328–0.02432 rad，hand6 jump为1.73–3.99 μm；动作哈希5/5不同，Strict 5/5。

manifest：`dataset_audit/state_conditioned_manifest.json`。

### 4.2 因果与动作合同

- 五条轨迹的strict replay controls均与记录ctrl一致；
- 每个control使用执行前的state/RGB/tactile；
- `pre_action_index_first=0`，每episode导出301帧；
- LeRobot实际feature为39D state、13D action、712D tactile、120×160×3 image；
- XYZ9 chunk由同一个当前anchor对未来Joint13 target做FK得到，不跨episode；
- 归一化只使用train roots 0–2，完整数值保存在`comparison_summary.json::normalization`和checkpoint buffers。

### 4.3 Root隔离

| Split | roots | frames |
|---|---|---:|
| train | 0,1,2 | 903 |
| validation | 3 | 301 |
| test | 4 | 301 |

同一root的前缀和后缀没有跨split，root leakage=0。测试只有1个root，因此只能做探索性配对，不能估计泛化成功率。

### 4.4 近重复和观测别名

五条episode的XYZ9 chunk两两RMSE仅为 `3.76e-05` 至 `1.72e-04`，表明“不同root”并未形成足够动作模式多样性。39D state最近1%配对中存在相似状态对应不同动作的情况；该检查未包含RGB，因此只能证明state端有别名风险，不能断言视觉一定无法区分。

更关键的结构问题是：每条轨迹由原始BC前缀后接新的pregrasp→approach规划。轨迹阶段顺序实际包含：初始pregrasp标记、10步BC approach、20步重新pregrasp、35步重新approach。对无历史的单帧BC，这会形成阶段回折和闭环动作歧义。

## 7. P17-D：冻结test root 4闭环

两组均使用同一root、同一初态、160×120、action_steps=4、340 steps、连续IK和原FINAL Strict。

| 指标 | 旧P6 | 新P17 |
|---|---:|---:|
| Approach wrist error steps 5–20 | 6.49 mm | 5.19 mm |
| 首次接触 | step 29 | 无 |
| contact fraction | 0.9147 | 0 |
| 逐指接触 | 5指均形成 | 0指 |
| 最大抬升 | 6.79 mm | 0.013 mm |
| 最终抬升 | −0.004 mm | −0.004 mm |
| FINAL Strict | 0/1 | 0/1 |
| IK/限位失败 | 0/0 | 0/0 |

新模型早期wrist误差略小，但只移动到距物体最小232.4 mm，未完成Approach，更没有进入Close接触。训练root 0诊断同样0接触、最大抬升0.013 mm，排除了“只在test root泛化失败”这一单一解释。

因此分层结论为：

1. **离线预测：改善。**
2. **Approach早期误差：轻微改善，但完整Approach严重退化。**
3. **接触形成：从旧模型有接触退化为0。**
4. **承载：无改善。**
5. **FINAL Strict：0/1→0/1，无改善。**

## 8. 延迟说明

本轮同机配对测得policy+IK P95约150–155 ms，明显高于历史P6约6.8 ms。两组都在本轮出现同样的高P95，且渲染P50约100 ms，说明当前机器/离屏渲染负载与历史条件不同。该数字不能归因于新模型结构（参数量完全相同），也不适合与历史低负载延迟直接比较。

## 9. 停止条件与失败分析

已触发：

- 新模型严重Approach遗忘；
- held-out和train root均0接触；
- validation与train存在明显gap；
- 有效root只有5个，test仅1个；
- 五条新增轨迹高度近重复。

因此没有：

- 调整模型结构、epochs、loss或sampling ratio；
- 将pitch不连续轨迹加入训练；
- 将test root移入训练；
- 再训练第二个seed；
- 启动ACT、DP、GRU或实机。

最有证据的根因排序：

1. 完整状态条件轨迹含BC前缀→重新pregrasp的阶段回折，不适合无历史单帧BC直接学习；
2. 5条轨迹动作高度近重复，未提供充分行为覆盖；
3. 仅3个训练root造成过拟合；
4. teacher-forced误差无法约束闭环访问状态。

## 11. 最终问题回答

### 1. 有多少状态条件轨迹通过数据审计？

5条，来自5个独立roots；均为xminus、FINAL、边界连续。其余10条仅作诊断，不进入监督集。

### 2. 是否建立无root泄漏训练集？

是。train/validation/test为3/1/1 roots，无交叉。但test仅1个root，证据强度有限。

### 3. 重训后Approach和Close是否改善？

早期wrist误差从6.49降到5.19 mm，但完整Approach退化，未发生任何接触，Close没有实际建立。

### 4. 承载和FINAL是否改善？

没有。最大抬升从6.79 mm降到0.013 mm；新旧均0/1 FINAL，新模型明显退化。

### 5. 新示教是否值得扩展？

状态条件规划能力值得保留，但**不能按当前“BC前缀+回到pregrasp+完整后缀”的形式直接扩展并训练单帧BC**。下一步应先重构示教：从查询状态规划单调、无回折的continuation，或明确只监督query后的后缀并使用可部署的阶段/历史条件；随后至少增加独立roots和非近重复动作，再决定是否重训。当前不应直接扩展到更多物体。
