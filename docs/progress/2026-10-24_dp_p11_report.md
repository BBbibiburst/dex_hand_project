# P11：全局视觉 + 高清 ROI 双分支模仿学习与 Close 承载抓持验证

## 1. Executive Summary

P11完成了独立root数据构建、公平A/B训练、两个未见root完整闭环和一个P9 Close snapshot精确配对实验。高清ROI提供了真实的新视觉细节，并提高了接触、多指接触及拇指对向接触的出现比例；但是这些提升没有转化为更好的承载跟随或FINAL验证。

两个未见root上，Global+ROI相较Global：

- 平均接触率：66.91% → 80.15%；
- 平均多指接触率：47.35% → 65.29%；
- 平均拇指对向接触率：37.06% → 45.00%；
- 平均object-following ratio：0.331 → -0.005；
- Strict成功：0/2 → 0/2。

同一P9 Close snapshot上，ROI策略保持接触更久（98.80% vs 59.84%），但Lift阶段object-following为-0.006，最终抬升-0.32 mm；Global策略一度形成0.847的跟随并最大抬升73.21 mm，随后在Verify阶段失稳、物体掉落，最终抬升-52.34 mm。两者均非成功。

结论：ROI对“看见接触并保持接触”有作用，但没有解决承载抓持。当前不满足加入触觉分支的门槛，也不应继续扩大视觉模型；下一阶段应回到Close/Hold时序示教与承载正例生成。

## 3. 实际数据合同

每个pre-action observation包含：

- `global_rgb`：直接从相同`agentview`状态渲染的160×120 RGB uint8 HWC；
- `local_rgb`：直接渲染1920×1080，然后以固定归一化ROI裁剪并双线性缩放为96×256 RGB；
- `state`：39D `actuator_position_velocity_command_v1`；
- `action`：共享当前anchor的16×9 XYZ9 future chunk。

固定ROI：

`[x0,y0,x1,y1] = [0.493229, 0.415741, 0.568229, 0.782407]`

## 5. 模型实现

新增独立模型`DualVisionActionChunkBC`，未修改原`ActionChunkBC`。

### Global基线

`160×120 RGB encoder(256) + 39D state encoder(256) → MLP → 16×9 XYZ9`

### Global+ROI

`global encoder(256) + local encoder(128) + state encoder(256) → MLP → 16×9 XYZ9`

两组action chunk、anchor、固定实测腕姿态、连续IK及action_steps=4完全相同。

ROI模型参数多13.0%，因此结果应解释为整个双分支架构的效果，不能将差异完全归因于ROI像素。

## 9. 延迟

当前机器EGL无法访问`/dev/dri`，渲染耗时异常偏高；以下是本环境实际端到端结果，不伪装成硬件GPU renderer吞吐。

两个test root平均：

| 模型 | Model P50/P95 | Observation→Action P50/P95 | 20 Hz |
|---|---:|---:|---:|
| Global | 2.77/41.57 ms | 100.23/144.69 ms | 端到端不满足 |
| Global+ROI | 28.72/59.03 ms | 201.84/254.56 ms | 不满足 |

ROI额外包含约78–84 ms的1080p渲染和约1.4–1.5 ms裁剪。模型自身P95在一个root为47.04 ms、另一个为71.02 ms，也不能稳定满足50 ms。由于ROI没有改善承载，本轮按止损规则不继续为失败策略做更小ROI或专用推理优化。

## 10. 失败分析

1. **ROI确实改变了策略行为**：root9和snapshot的接触、多指接触显著增加，不是“ROI完全未被利用”。
2. **新增行为偏向接触保持而非承载几何**：高接触下object-following接近0，说明物体没有随腕部Lift。
3. **离线action MSE不支持明显优势**：两组validation MSE均约0.0092。
4. **示教监督仍不足以区分接触与可承载接触**：当前loss对所有XYZ9/hand维度统一回归，没有显式承载阶段正负对照。
5. **Global也不稳定**：root8一度携物但尾段高速，root9完全失败；这不是ROI单独造成的问题。
6. **视觉不是当前唯一或主要瓶颈**：更清晰局部视觉提高了接触统计，却未提高Strict与承载。

## 11. 触觉门槛

当前不具备继续加入712D tactile的条件。原因不是触觉无用，而是RGB ROI尚未建立可信的承载提升；此时再加入触觉会同时改变输入、参数量和训练难度，无法解释因果。应先生成包含稳定承载正例、滑移/失稳负例并按独立root划分的Close/Hold数据，再考虑触觉条件化残差或readiness检测。

## 13. 最终问题回答

**高清ROI是否提供了有用的新信息？** 提供了。局部边缘可见性更好，且闭环接触统计发生明显变化。

**ROI是否改善Close阶段承载抓持？** 没有。它改善了接触出现/保持，但object-following没有改善，snapshot中反而由0.847降至-0.006。

**最终Strict成功率是否改善？** 没有。两个独立test root均为Global 0/2、Global+ROI 0/2；snapshot均0/1。

**推理是否满足20 Hz？** 不满足。ROI模型P95平均59.03 ms，完整观测到动作P95平均254.56 ms；当前headless EGL渲染是主要额外开销之一。

**下一步转向哪里？** 转向Close/Hold时序示教生成和承载状态监督，而不是继续扩大视觉。优先生成能够区分“持续接触但不承载”和“真正随腕Lift”的配对轨迹，再训练阶段化/残差控制；触觉应在有正负承载数据后加入。
