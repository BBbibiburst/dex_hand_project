# P48：多步对抗触觉迁移的四路线统一评价实验

**实验性质：冻结模型评价、统计审计与多步迁移路径分析。**

**核心目标：** 使用现有 P44/P45 模型，分别从 Jensen-Shannon Divergence（JSD）、Wasserstein 距离、多步路径一致性、统计等价性四个角度，评价共享参数多步对抗迁移方法是否真正缩小 Natural Sim 与 Real 触觉之间的差异。

本轮不训练或修改任何迁移模型，不改变原始数据、C0、Scaler、训练划分及历史验收协议。

---

# 一、首先理解为什么要做这项实验

之前的实验主要使用冻结分类器 BA、AUC、D 判断迁移效果，但我们发现：

1. BA 和 D 可能因为迁移数据几乎全部被判为 Real 而达到很高的分数。
2. AUC 仍能发现分类器可以利用连续分数区分两个域，但它不能直接表达迁移消除了多少原始差异。
3. RVC 可以描述迁移数据是否进入 Real 的自然变异范围，但 P46 发现常量输出、Real Donor 等负对照也可能通过。
4. P47 进一步表明，边际分布接近不等于局部结构、输入依赖和时序结构正确。

因此，本轮不再单纯寻找一个分类器混淆指标，而是从四个不同层面评价迁移：

**第一，分布差异消除了多少？**

使用 JSD 相对差异消除率。

**第二，分布之间的运输距离缩短了多少？**

使用 Sliced Wasserstein Distance（SWD）。

**第三，多步迁移过程是否合理？**

分析每一步的迁移方向、幅度、距离变化和稳定性。

**第四，最终差异是否已经进入 Real 自身的自然变异范围？**

使用基于 Real–Real 统计分布校准的等价性检验。

这四条路线回答不同的问题，不能简单加权为一个人为的总分。

特别注意：

本实验中的 90% 是原始 Sim–Real 差异的相对缩减目标，不是 90% 的样本被判为 Real，也不是 90% 的 Root 通过率。

# 三、路线 A：JSD 相对分布差异消除率

## 3.1 研究目的

JSD 是 GAN 理论中非常重要的分布差异度量。

原始 GAN 理论表明，在判别器达到最优的情况下，最优判别器的对抗交叉熵与生成分布和真实分布的 JSD 存在直接关系。

我们希望利用这个关系回答：

**多步迁移之后，原始 Sim–Real 分布差异究竟消除了多少？**

设：

- P_R：Real 分布。
- P_0：原始 Natural Sim 分布。
- P_k：经过第 k 个迁移配置后的 Sim 分布。

计算：

`J_0 = JSD(P_R,P_0)`

`J_k = JSD(P_R,P_k)`

定义：

`R_JS(k) = 1 - J_k/J_0`

目标：

`R_JS(k) >= 0.90`

即迁移后的分布差异不超过原始差异的 10%。

## 3.2 如何估计 JSD

采用独立分类器的 held-out Log Loss 估计。

在两个域先验概率相等的条件下，最优判别器的最小交叉熵满足：

`CE* = ln(2) - JSD(P_R,P_S)`

因此：

`JSD_proxy = ln(2) - CE_validation`

这里必须严格区分：

- 最优判别器对应理论 JSD。
- 实际有限容量分类器得到的是分类器受限的 JSD 代理估计。

不能直接宣称有限模型计算出的数值就是真实 JSD。

## 3.3 独立判别器训练

对 Original、A/B/C 的各个 K，分别训练同一套独立审计分类器。

要求：

1. 使用 Real Train 和对应迁移后的 Sim Train。
2. 每个候选使用完全相同的分类器架构、训练预算和优化器。
3. 重新初始化分类器，不使用原 C0 权重。
4. 类别总权重相等。
5. Session/Root 组内等权，避免大组主导训练。
6. 不使用 Validation 做早停、调参或模型选择。

审计分类器至少包含：

- Logistic：线性判别能力。
- MLP：非线性全维判别能力。
- GRU：时序判别能力。

MLP、GRU 使用固定 Seed 11/12/13。

尽量复用原 C0 的网络结构和训练配置，但必须重新初始化参数。

所有模型采用同一套固定训练预算。Logistic 必须检查优化收敛情况；若达到迭代上限仍未收敛，标记该结果无效，不得把未收敛当成高混淆。

不允许根据哪个分类器给出更高的迁移成绩而挑选结果。

## 3.4 验收统计

每个判别器报告：

- Validation Log Loss。
- JSD_proxy。
- 原始 JSD_proxy 基线。
- 相对差异消除率 R_JS。
- BA、AUC（仅作辅助诊断）。
- Train/Validation 收敛情况。

Bootstrap 必须以 Real Session 和 Sim Root 为聚类单位，按 Sim 任务分层重采样。

建议固定 1000 次，保留 Seed。

不能将窗口当成独立样本计算置信区间。

重要停止条件：

如果原始 Sim–Real 的 JSD_proxy 本身接近零，或者其组 Bootstrap 区间无法支持正的初始差异，则分母不可靠，90% 相对消除率不可估计。

不得通过截断负数、调整分母或挑选分类器制造 90%。

最终逐个报告分类器和 Seed。只有预先注册的分类器家族整体支持这一结果，才能宣称获得稳健的 90% JSD 代理差异消除。

# 四、路线 B：Wasserstein 相对距离缩减率

## 4.1 研究目的

JSD 主要通过判别能力反映分布差异，而 Wasserstein 从运输成本角度衡量两个分布之间的距离。

它可以提供与分类器不同的评价视角。

定义：

`W_0 = SWD(P_R,P_0)`

`W_k = SWD(P_R,P_k)`

相对缩减率：

`R_W(k) = 1 - W_k/W_0`

目标：

`R_W(k) >= 0.90`

## 4.2 具体方法

本轮使用 Sliced Wasserstein Distance：

1. 使用完整 2848 维数据。
2. 使用固定的 1024 个随机投影方向。
3. 投影方向固定 Seed。
4. 所有方法和 K 共用完全相同的投影方向。
5. 每个方向计算两个加权一维经验分布的 Wasserstein-1 距离。
6. 对所有方向取平均。

必须使用组等权经验分布。

报告：

- Original Sim 的 SWD。
- A/B/C 各 K 的 SWD。
- 相对距离缩减率。
- 每个投影方向的统计结果。
- 1000 次 Session/Root 分组 Bootstrap 区间。

这里得到的是 SWD，不能把它直接写成完整高维 Wasserstein-1。

如果原始 SWD 分母接近零，或者不确定性过大，则相对缩减率不可解释。

不允许根据结果重新挑选投影方向。

# 五、路线 C：多步迁移路径一致性

## 5.1 研究目的

这是本轮与 P44 方法最直接相关的部分。

我们不应该只评价最终 K 步的输出。

还应该回答：

**同一套迁移参数在不同步数下，究竟如何改变触觉数据？**

如果模型真正实现了稳定的多步迁移，那么迁移路径应当具有可解释的变化过程。

## 5.2 路径数据

对 A/B/C 分别执行冻结推理。

尽可能保存每一步的实际中间状态：

`x_0 -> x_1 -> x_2 -> ... -> x_K`

如果内部状态是潜变量：

- 必须核验使用的 Encoder/Decoder。
- 优先通过原有冻结 Decoder 解码到完整 712D。
- 不得直接把两个未经认证共享坐标系的独立潜空间进行欧氏距离比较。
- 如果中间状态无法合法解码，则只报告模型内部的轨迹变化，不把它冒充完整触觉分布变化。

所有中间状态使用同一批输入样本和同一索引。

不得重新训练网络。

## 5.3 路径指标

至少报告以下内容：

**① 每一步分布距离**

对可以解码的 712D 中间状态计算 SWD：

`SWD_0, SWD_1, ..., SWD_K`

观察整体是否朝 Real 分布靠近。

**② 单步更新幅度**

`Delta_k = x_(k+1) - x_k`

报告：

- 更新向量的平均 L2 Norm。
- 更新幅度的 P50/P90/P95。
- 每一步的更新幅度变化。

**③ 相邻更新方向一致性**

计算：

`Cosine(Delta_k,Delta_(k-1))`

观察迁移是否出现频繁方向反转。

**④ 路径长度与端点距离**

`PathLength = sum(||Delta_k||)`

`EndpointDistance = ||x_K-x_0||`

`PathRatio = PathLength / max(EndpointDistance,epsilon)`

用于分析迁移是否出现过多无效绕行。

**⑤ 路径反弹**

记录每一步分布距离增加的次数、最大反弹幅度以及最终距离相对最优中间步的变化。

注意：

不要求每一步 SWD 严格单调下降。

如果 K=4 最好，而 K=8 反而变差，应当如实说明存在过度迁移、数值误差或其他问题。

不能事后只选择最好的中间步骤来代替原定最终输出。

# 六、路线 D：统计等价性检验

## 6.1 研究目的

JSD 和 SWD 的相对缩减率回答的是差异消除了多少。

但我们还需要一个不同的问题：

**迁移后的 Sim 与 Real 之间剩余的差异，是否已经小于 Real 自身正常采集变异所能解释的范围？**

这里使用统计等价性检验，而不是简单地判断 MMD 是否较小。

## 6.2 Real–Real 自然变异校准

复用 P46 的 MMD 计算合同：

- 完整 2848D 输入。
- P46 固定预处理。
- 固定 sigma=30.251723。
- 多尺度 RBF Kernel：0.5σ、σ、2σ。
- 使用 MMD V-statistic。
- 不改变 Kernel 或距离定义。

但这次重新建立与 Validation 组数量相匹配的 Real–Real 校准：

Real Train 共 32 Session。

从中随机选择两组互不重叠的 Session：

- 第一组 4 Session。
- 第二组 10 Session。

每个 Session 固定抽取 7 个窗口，保持组等权。

使用固定 Seed 进行 1000 次不重叠组划分抽样。

得到 Real–Real 的自然差异参考分布。

将其 95% 分位数记为：

`epsilon_RR`

该值只由 Real Train 确定，不能根据迁移成绩调整。

## 6.3 最终等价性检验

对每个迁移方法：

使用 Real Validation 的 4 Session 和对应迁移 Sim Validation 的 10 Root。

每个组同样抽取 7 个窗口，使用相同的预处理、Kernel 和权重合同。

计算：

`Delta_eq = MMD(TranslatedSim,Real) - epsilon_RR`

通过条件：

`Delta_eq 的 95% Bootstrap 置信区间上界 < 0`

即迁移后的整体分布距离已经小于 Real–Real 自身自然变异的预先校准容限。

Bootstrap 必须同时考虑：

- Real Validation Session。
- Sim Validation Root。
- Real–Real 校准组。

这项检验只表示当前采样条件下的边际统计等价，不代表物理触觉语义完全等价。

**不得把它重新命名为 RVC，也不得再计算一个人为的 RVC 通过率。**

## 6.4 必须进行负对照

至少包含：

1. Original Sim：未迁移数据。
2. Constant：所有 Sim 输入均输出同一个 Real Train 均值。
3. Real Donor：每个 Sim 输入独立分配一个 Real Train Donor。
4. Pair Shuffle：保留迁移输出边际分布，但在相同任务/阶段条件内打乱输入输出对应关系。

这些对照用于检查等价性检验是否具有鉴别能力。

特别注意：

- Constant 可能通过边际距离，但应当被多样性指标识别。
- Real Donor 可能通过边际距离，但应当被输入依赖指标识别。
- Pair Shuffle 理论上保持边际分布不变，因此不能要求 MMD 或 SWD 拒绝它；必须依赖条件对应关系评价发现它。

如果负对照没有被相应的质量或条件指标识别，必须明确指出联合评价仍然不充分。
