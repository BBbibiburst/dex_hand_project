## 8. 决策：哪些结论成立

1. **Mask是否必要？** 对当前数据上的域识别，显式Mask不是必要条件，连续D本身已经很强；对成功迁移，A/C都未给出完成证据。
2. **梯度断点是否影响优化？** 是。C修复了D→G的占用梯度并明显改变了训练结果；但没有获得联合收益，且产生幅值/多样性收缩，所以断点不是唯一障碍。
3. **连续712D能否替代显式Mask？** 作为判别器输入可行；作为已验证的成功迁移方案尚不成立。A有描述性AUC改善，质量仍未过关。
4. **哪条最值得保留？** 若以后继续，A是较简单、较有价值的表示候选，优先研究它的尾部/保持约束矛盾；这只是优先级，不升级默认模型、不立刻开P46。
5. **还不能解释什么？** 单Seed、历史Validation反复使用、A参数量/有效R1差异、任务/阶段/采样协议与Decoder伪影的独立贡献未分离。不能把所有失败归为Mask、容量或单一物理因素。

本轮不满足预设A/B/C成功情形；更接近“没有得到可接受迁移改善”的情形D，同时C有结构退化。它不是情形E的假成功，因为没有一组完整联合AUC通过。**停止Mask/温度搜索，不换GAN架构，不启动P46。**

## 9. 复现与保护

A/generator.pt、A/discriminator.pt和C对应文件为唯一端点模型。B只引用P44原权重/结果，新增B轨迹为冻结推理补充。code/infer.py可用同一组G权重指定K，完整Generator仍包含原冻结双VAE，不需要D、Real或独立G0。

```bash
python code/infer.py --checkpoint A/generator.pt --input NATURAL_WINDOWS.npz --key values --K 8 --output NEW_OUTPUT.npz
```
