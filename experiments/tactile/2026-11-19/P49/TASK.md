# P49：多步对抗迁移与逐轮冻结判别器90%验收实验

项目：`/home/zmy/dex_hand_project`

实验性质：单Seed、有限预算、基于P48 Continuous-only路线的多步对抗迁移实验。

核心目标：建立一套逐轮更新、逐轮冻结的对抗迁移机制，以冻结判别器对迁移Sim的Real接受率 FR ≥ 0.90 为主要目标，同时保证输出仍然具有真实的输入依赖、空间结构、幅值分布和时序特征。

# 一、首先理解本实验为什么要做

我们目前的研究目标是：

将Natural Sim产生的完整712D触觉数据，经过迁移生成器处理，得到具有Real-like统计特征、同时保留原始输入信息的完整触觉数据。

此前已经尝试过：

1. GMM及潜空间映射；
2. Dual-VAE；
3. Translator；
4. P44共享参数时间条件向量场；
5. Continuous-only、Hard-Mask和STE-Mask；
6. 多种分布距离和Real自然变异包络。

P48目前最值得继续的是Continuous-only路线。

历史结果显示，A_K1的SWD从约0.4113下降到0.2066，缩减约49.77%，Bootstrap区间为40.85%–56.67%。

但目前仍然存在问题：

- Decoder输出与潜空间路径存在不一致；
- 时序统计仍有明显差异；
- SWD改善不等于完整712D触觉已经完成迁移；
- Constant、Real Donor等负对照也能获得一定程度的距离改善。

因此，不能仅仅继续降低SWD，也不能只追求某个分类器的AUC接近0.5。

我们现在提出一个新的验收思路：

**利用多轮对抗训练，让每一轮的判别器针对上一轮迁移结果重新学习剩余域差异，再冻结判别器，让同一套生成器继续消除这些差异。**

这才是本实验真正要验证的内容。

# 二、明确三个模型及其职责

## 2.1 生成器 Fθ

使用P48已有的Continuous-only生成路线作为初始模型。

记为：

F_0 = A_K1

要求：

- 保留原来的Dual-VAE及现有迁移架构；
- 保留共享参数时间条件向量场；
- 保留已有Decoder及完整712D读出；
- 不重新设计一套独立生成器；
- 不把最终输出停留在潜空间或Mask空间。

最终接口必须是：

输入：

`Natural Sim tactile: [N, 4, 712]`

输出：

`Translated tactile: [N, 4, 712]`

输出必须finite、非负，并保留原始窗口对应关系。

具体哪些模块冻结、哪些模块可训练，必须先检查P44至P48的真实代码和Checkpoint，不得凭任务书自行假设。

## 2.2 判别器 Dφ

使用P44已有的全局判别器架构。

如果现有实现不完整，先检查已有代码，优先补齐原架构，不要随意增加大型判别网络。

判别器输入：

- Real完整712D触觉；
- 当前阶段生成的完整712D迁移Sim。

标签固定：

- Real = 1；
- Translated Sim = 0。

判别器输出Real概率：

`p_real = sigmoid(Dφ(x))`

阈值固定为0.5。

## 2.3 两套模型共享参数

这是本实验的重要要求。

不是每轮重新创建一个生成器和一个判别器。

而是：

- 始终使用同一个Fθ参数；
- 始终使用同一个Dφ参数；
- 每轮保存Checkpoint快照；
- 下一轮继续从上一轮的参数更新。

也就是说，模型参数不断演进，而不是每一轮从头训练。

# 三、核心方法：多轮交替对抗训练

这是本实验最重要的部分，请严格按照以下顺序理解和实现。

## 初始阶段：建立原始域判别能力

首先使用原始Sim和Real训练初始判别器D_0。

数据：

- 原始Natural Sim Train；
- 原始Real Train。

目的：

验证当前判别器架构有能力识别原始两个域。

保存：

- D_0；
- 训练日志；
- Train与内部Group Validation的BA、AUC、混淆矩阵。

如果D_0连原始Sim和Real都不能有效区分，先停止，不进入对抗训练。

随后加载P48的A_K1作为初始生成器F_0。

## 第一轮：D_1与F_1

**第一步：训练判别器**

将F_0(S)与Real进行比较。

使用同一套Dφ参数继续训练，使其学习：

- F_0(S) → Sim；
- Real → Real。

训练完成后，保存D_1并冻结所有判别器参数。

**第二步：训练生成器**

冻结D_1。

使用同一个Fθ，继续更新生成器，使：

`D_1(F_1(S)) → Real`

核心对抗损失：

`L_adv = BCEWithLogits(D_1(Fθ(S)), 1)`

同时保留P48已有的输入保持、结构和其他必要损失。

不能为了欺骗判别器而直接抹除原始触觉信息。

**第三步：评价**

冻结D_1不变。

使用D_1评价：

- 原始Real；
- F_0(S)；
- F_1(S)。

记录迁移前后的Real接受率变化。

这一阶段的核心问题是：

生成器经过更新后，能否在没有重新训练判别器的情况下，使更多迁移Sim被认成Real？

## 第二轮：D_2与F_2

如果第一轮完成：

1. 继续使用同一套Dφ参数；
2. 使用F_1(S)与Real继续训练判别器；
3. 得到D_2；
4. 冻结D_2；
5. 使用同一个Fθ继续训练，得到F_2；
6. 使用D_2评价F_2(S)。

## 后续轮次

完全重复上述过程：

`F_0 → D_1 → F_1 → D_2 → F_2 → D_3 → F_3 ...`

其中：

- D_k负责识别第k-1轮迁移结果的剩余差异；
- F_k负责欺骗冻结的D_k；
- 每一轮只更新同一套Fθ和Dφ；
- 每一轮都保存完整Checkpoint。

**非常重要：**

D_k必须在F_k训练之前完成训练并冻结。

评价F_k时，不能先拿F_k重新训练D_k，否则判别器已经看过当前输出，不能再称为本轮冻结判别器验收。

# 四、核心90%指标：FR

此前的D指标：

`D_old = 1 - 2 * abs(BA - 0.5)`

存在明显问题。

当判别器把几乎所有样本都预测成Real时，也可能得到接近1的D_old。

因此本实验不再使用D_old作为主要成功指标。

重新定义：

**FR = Frozen Discriminator Real Acceptance Rate**

对于第k轮：

`FR_k = mean(1[p_Dk(Real | F_k(S)) >= 0.5])`

也就是：

迁移后的Sim数据中，有多少比例被第k轮冻结判别器认定为Real。

目标：

`FR_k >= 0.90`

## 4.1 必须同时记录三个数值

1. `FR_pre`：生成器更新前，D_k对F_(k-1)(S)的Real接受率。
2. `FR_post`：生成器更新后，D_k对F_k(S)的Real接受率。
3. `Real_acceptance`：D_k对真实Real数据的Real接受率。

主要验收：

- FR_post ≥ 0.90；
- Real_acceptance ≥ 0.90。

此外必须检查D_k在生成器更新之前是否具有有效的判别能力。

如果D_k在更新前就无法区分当前迁移Sim和Real，不能简单把之后的FR高解释为生成器取得了新的对抗收益。

需要区分：

- 已经达到混淆状态；
- 判别器训练不足；
- 判别器在训练组过拟合；
- 生成器真正改善了迁移。

## 4.2 按独立组计算FR

不能只把所有窗口混在一起计算一个比例。

当前注册数据为：

Real：

- Train：5153窗口、32 Session；
- Validation：780窗口、4 Session。

Natural Sim：

- Train：4049窗口、50 Root；
- Validation：905窗口、10 Root。

实际执行前必须重新核对注册文件。

主FR采用Root等权宏平均：

先计算每个Sim Validation Root内部的Real接受率，再对10个Root求平均。

同时报告：

- 全部窗口的Micro FR；
- Root Macro FR；
- 每个Root的FR；
- 每个任务的FR；
- Real Session Macro Acceptance。

这样可以避免某个数据量较大的Root主导结果。

使用固定0.5阈值，不得根据Validation调整阈值。

报告分组Bootstrap置信区间，不能将重复窗口当成独立物理采集单位。

# 五、辅助指标：防止生成器作弊

FR是本实验的主要目标，但不能单独作为最终成功依据。

我们要证明生成器生成的是有意义的Real-like触觉，而不是简单地欺骗判别器。

请尽量复用P46、P48已经实现的评价代码，不要重新创造一套指标体系。

## 5.1 分布指标

继续记录：

- SWD；
- MMD；
- PRDC；
- 必要时Energy Distance。

重点观察：

1. 相比Original Sim，迁移后的分布距离是否持续下降；
2. 相比A_K1，后续对抗轮次是否进一步改善；
3. Precision、Recall、Density、Coverage是否出现模式坍塌。

不要求这些指标全部达到0.90。

它们负责证明FR提升不是以破坏数据分布为代价。

## 5.2 输入依赖指标

这是必须重点检查的内容。

迁移输出必须依赖对应的原始Sim输入。

记录：

- HSIC；
- 输入输出依赖程度；
- 配对与随机错配对照；
- 生成输出的多样性。

特别执行Pair Shuffle负对照：

保持生成数据边际分布不变，仅打乱输入与输出的对应关系。

预期：

- FR及边际SWD可能基本不变；
- 输入输出依赖指标应该明显下降。

如果Pair Shuffle后所有指标仍然通过，说明目前的验收体系无法证明输入保持，不能宣布成功。

## 5.3 空间和幅值指标

记录：

- 零值比例；
- 正值幅值分位数P1/P10/P50/P90/P95/P99；
- 空间激活结构；
- Mask统计；
- 窗口间差异；
- 唯一输出数量。

不允许通过全部输出相同的数值、固定模板或极小随机噪声骗过判别器。

## 5.4 时序指标

记录：

- 相邻帧变化；
- Lag-1相关性；
- 时序幅值分布；
- 接触状态持续情况；
- 各阶段的统计结果。

注意Real和Sim采样频率及任务流程尚未完全认证一致。

不得把不同采样间隔下的相邻帧变化直接解释为相同物理时间尺度下的动力学。

## 5.5 三种负对照

必须使用与正式生成结果相同的评价流程。

**Control A：Constant**

使用固定的Real Train均值生成完整触觉。

**Control B：Real Donor**

直接使用随机Real Train样本作为输出，不保留与Sim输入的对应关系。

**Control C：Pair Shuffle**

使用正常迁移结果，但随机打乱输入与生成结果的配对关系。

要求：

- 记录三种控制的FR；
- 记录分布指标；
- 记录输入依赖；
- 记录多样性；
- 记录空间与时序结构。

Constant和Real Donor即使获得较高FR，也不能因此通过完整验收。

Pair Shuffle如果没有被输入依赖指标识别出来，则说明质量验收存在漏洞。

# 八、最终验收标准

本轮最终结果分为三种情况。

## A类：成功

同时满足：

1. 最终冻结判别器的Root Macro FR ≥ 0.90；
2. Real Acceptance ≥ 0.90；
3. 判别器训练有效，没有明显过拟合或失效；
4. SWD/MMD等分布指标没有明显退化；
5. PRDC没有明显模式坍塌；
6. HSIC及输入依赖指标通过Pair Shuffle对照；
7. 幅值、空间和时序结构没有明显退化；
8. Constant、Real Donor等负对照无法通过完整质量验收。

可以报告：

**在当前注册数据、判别器架构及评价协议下，完成90%冻结判别器Real接受率目标。**

不要将其扩大解释为所有真实传感器分布都已完全一致。

## B类：部分成功

FR达到0.90，但部分质量指标没有通过。

此时说明生成器已经学会欺骗冻结判别器，但还没有证明生成质量合格。

不得宣布完整迁移完成。

## C类：失败

FR没有达到0.90，或者出现明显模式坍塌、输入依赖丢失、时序结构退化、判别器过拟合等问题。

需要给出明确的失败原因，不允许通过更换指标宣布成功。
