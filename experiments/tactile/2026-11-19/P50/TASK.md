# P50：基于残差触觉重建与多视角判别器的对抗迁移架构改进

日期：2026-11-19

项目：dex_hand_project

实验性质：单 Seed、单轮对抗架构可行性实验。

核心目标：解决 P49 中冻结判别器 Real Acceptance 达到 100%，但完整 712D 输出质量退化的问题。

---

# 一、为什么要做 P50

请先完整理解 P49 的结论，再开始实施。

P49 已经验证了一套逐轮更新、逐轮冻结判别器的触觉对抗迁移机制：

1. 判别器学习识别当前迁移 Sim 与 Real 的差异。
2. 冻结判别器。
3. 更新生成器，使迁移结果被冻结判别器接受为 Real。
4. 更新下一轮判别器，重新识别当前迁移结果。
5. 重复上述过程。

P49 的 F3 最终达到：

- Root Macro FR：100%。
- Root Micro FR：100%。
- Real Session Macro Acceptance：100%。

但是完整质量没有通过：

| 指标 | F0 | F1 | F2 | F3 |
|---|---:|---:|---:|---:|
| SWD | 0.2066 | 0.5307 | 0.2864 | 0.4113 |
| MMD | 0.3437 | 0.8336 | 0.5179 | 0.6768 |
| PRDC Precision@5 | 0.1089 | 0 | 0 | 0 |
| PRDC Recall@5 | 0.0399 | 0 | 0.0010 | 0 |
| 跨窗口 Std | 0.05478 | 0.000201 | 0.02311 | 0.03166 |

最重要的发现：

**P49 的对抗训练能够改变判别器的分类结果，却没有保证完整触觉数据的分布质量。**

第一轮 F1 甚至出现了严重的样本收缩。

这意味着当前问题不是简单地增加对抗轮数或调整学习率就能解决的。

我希望 P50 针对两个具体问题进行架构改进。

## 研究方向 A：Output Residual Refiner

当前生成器已经具备：

- Dual-VAE；
- 共享参数向量场；
- Translator；
- Real Decoder；
- 完整 712D 输出能力。

不需要重新设计这些基础模块。

问题在于，潜空间迁移之后，经过 Real Decoder 得到的完整触觉输出仍然存在幅值、空间和时序结构偏差。

因此，在现有生成器后增加一个轻量级残差修正网络 Rψ。

原流程：

Natural Sim → Dual-VAE → Fθ → Real Decoder → 712D输出

新流程：

Natural Sim → Dual-VAE → Fθ → Real Decoder → Rψ → 712D输出

数学表达：

Y₀ = Decoder(Fθ(S))

Y₁ = Y₀ + Rψ(Y₀, Z)

其中 Z 为当前样本对应的生成器潜变量或条件特征，不允许使用 Real 样本的配对真值作为推理输入。

Rψ 的职责：

1. 修正完整输出的幅值分布。
2. 修正不同 Taxel 的响应结构。
3. 改善四帧窗口内的时序变化。
4. 保留原始 Sim 输入与输出之间的样本对应关系。
5. 避免对抗训练导致输出趋同或近模板化。

实现要求：

- Rψ 使用零残差初始化，使初始输出尽可能严格等于 F0。
- 保证输出 finite、非负。
- 保留完整 712D 通道，不删除、不重排。
- 可以采用适合连续响应数据的残差参数化，但必须通过梯度检查。
- 不允许通过固定 Real 样本、随机 Real donor 或无条件生成来改善边际统计。
- 不允许让 Refiner 直接读取 Real Validation。
- 保留现有 preserve 和 flow 损失，系数沿用 P49，不根据 Validation 调整。

Fθ 的共享向量场继续可训练，Rψ 新增可训练。Dual-VAE 和 Real Decoder 全部冻结。

特别注意：Rψ 应当是对现有生成结果的修正，而不是另起一套生成模型。

## 研究方向 B：Multi-view Discriminator

P49 的判别器主要通过一个全局分类结果衡量 Real/Sim 差异。

这存在明显不足：

- 全局统计可能掩盖局部空间差异。
- 整体幅值接近不代表激活区域正确。
- 四帧整体分布接近不代表时序结构正确。
- 单一分类输出容易被某些局部统计特征欺骗。

因此设计一个多视角判别器。

输入始终是完整 712D 触觉：

X ∈ R[N,4,712]

设置三个判别分支。

### 1. Global Discriminator

输入：完整四帧连续触觉数据。

使用 log1p 后的完整响应，判断整体分布是否接近 Real。

主要学习：

- 全局幅值分布；
- 零值与弱响应结构；
- 整体响应统计；
- 不同窗口之间的分布差异。

### 2. Spatial Discriminator

输入：根据已有 16 Patch 通道映射构造的连续空间响应特征。

主要学习：

- Patch 激活分布；
- 不同区域的响应强度；
- 局部响应集中程度；
- 空间响应结构。

必须先检查项目中已有的 712D 到 16 Patch 映射代码。

不得假定索引相邻就意味着真实物理位置相邻。当前物理 Taxel 映射尚未完全认证，因此空间判别结论限定为现有 Patch 索引结构。

### 3. Temporal Discriminator

输入：完整四帧连续触觉的相邻帧变化特征。

例如：

ΔXₜ = log(1+Xₜ₊₁) - log(1+Xₜ)

主要学习：

- 相邻帧响应变化；
- 局部响应持续性；
- 窗口内动态变化；
- 时序统计结构。

注意：Real 数据采样间隔不均匀，Sim 约为 20Hz。当前分支只能评价四帧窗口的索引时序结构，不得将其解释为经过物理时间校准的动力学一致性。

### 4. 判别器结构

三个分支可以使用各自的轻量级特征编码器，也可以共享合理的底层特征。

最终分别输出：

D_global(X)

D_spatial(X)

D_temporal(X)

三个分支均采用 Real=1、Sim=0 的二分类任务。

对抗损失：

L_adv = (L_global + L_spatial + L_temporal) / 3

生成器希望三个分支都将迁移结果判为 Real。

**重要：新判别器必须直接使用连续、可微的 712D 响应及其派生特征。**

P49 中的硬 Mask 阈值操作不能向生成器提供有效梯度，这是本次必须解决的问题之一。

本轮不再把不可微的二值 Mask 作为唯一空间判别输入。

Mask 可以继续用于离线质量统计，但不能阻断生成器的空间结构修正梯度。

请分别对三个判别分支执行梯度 Smoke Test，确认梯度能够经过判别器传回 Fθ 和 Rψ，并检查各通道梯度是否有限。

# 三、P50 实验流程

本轮只进行一次对抗外循环，不自动进入第二轮。

使用单 Seed=5001。

## 阶段 0：基线与数据审计

读取：

- P45 F0；
- P49 F0–F3；

|---|---:|

| Natural Train | 4049 窗口，50 Root |
| Natural Validation | 905 窗口，10 Root |

生成器输出必须能够与 P49 F0 的对应输出逐窗口核对。

不读取 Test/Holdout。

## 阶段 1：生成 F0 基线输出

使用现有 F0 生成 Natural Train 和 Natural Validation 的完整 712D 输出。

Natural Train 用于训练新判别器及生成器。

Natural Validation 仅用于最终评价。

输出：

- F0 Train；
- F0 Validation；
- 数据 Hash；
- 输入输出配对审计；
- 完整质量指标。

不能重新训练 Dual-VAE。

## 阶段 2：训练 Multi-view Discriminator

使用 F0(Natural Train) 与 Real Train。

训练目标：

让三个判别分支分别识别迁移 Sim 和 Real。

沿用 P49 的分组隔离思路：

- Real：24 Session fit / 8 Session inner。
- Sim：40 Root fit / 10 Root inner。

使用组均衡采样，防止大 Session 或大 Root 主导训练。

三个分支使用类别均衡损失，保持 Real=1、Sim=0。

建议沿用 P49 判别器训练预算：10 Epoch，最多660步，具体按现有数据加载合同核验。

训练完成后保存完整 D50 Checkpoint。

评价：

- 每个分支的 Train/Inner BA；
- 每个分支的 AUC；
- 混淆矩阵；
- Sim Recall；
- Real Recall；
- Session/Root 分组结果；
- 概率分布；
- CE 及 Train/Inner 差距。

CE 差距只作诊断，不新增 0.2 之类的硬停止条件。

如果出现分支输出常量、梯度异常或严重数据泄漏，停止并报告，不得删除表现不佳的分支来制造结果。

注意：这里的分组 Inner 是判别器训练诊断，不是 F0 未见过的生成器盲测。必须如实披露。

## 阶段 3：冻结判别器，训练新生成器

初始化：

F0 的共享向量场 + 新增 Rψ。

冻结：

- Dual-VAE；
- Real Decoder；
- D50 的全部参数。

训练：

- 共享向量场 Fθ；
- Refiner Rψ。

生成器目标：

L_G = L_adv + 0.5295653698327406 × L_preserve + 0.001 × L_flow

其中 L_adv 为三个判别分支 BCE 的等权平均。

preserve 和 flow 完全沿用 P49 原定义。

不根据 Validation 调整损失权重。

建议沿用 P49 单轮 G 预算：20 Epoch、最多1280步。

训练期间记录：

- 三个判别分支的对抗损失；
- preserve；
- flow；
- Refiner 残差范数；
- 生成器参数更新量；
- 各分支向生成器传递的梯度范数；
- 输出的非负性、有限性和多样性。

每个 Epoch 保存 Checkpoint，但主结果固定使用预先登记的20 Epoch终点模型，不根据 Validation 挑选最有利的 Epoch。

判别器必须始终冻结，保存训练前后 Hash 进行核验。

## 阶段 4：最终独立评价

使用最终 F50 对 Natural Validation 生成完整 712D 输出。

使用同一份 Real Validation。

对照：

1. Original Natural Sim；
2. P45 F0；
3. P49 F3；
4. P50 F50。

必须保持完全一致的数据窗口、Scaler、通道顺序和评价公式。

# 四、正式评价指标

本轮不重新设计评价体系，直接沿用 P49 已登记的完整质量护栏。

## 1. Real Acceptance

三个判别分支分别报告 FR。

另外定义联合接受：

只有 Global、Spatial、Temporal 三个分支均以固定0.5阈值判为 Real，该窗口才算联合接受。

报告：

- Global FR；
- Spatial FR；
- Temporal FR；
- Joint FR；
- Root Macro FR；
- Root Micro FR；
- Real Session Macro Acceptance；
- 各 Root、Session 的独立结果。

主要目标：

Joint Root Macro FR ≥90%。

Real Session Macro Acceptance ≥90%。

不改变阈值，不按 Validation 搜索最优阈值。

AUC 完整报告，但不要求必须等于0.5，也不以 AUC 单项否决 FR。

同时保留混淆矩阵，避免将全部样本预测为 Real 的现象隐藏起来。

## 2. 分布质量

沿用 P49 的：

- SWD；
- MMD；
- PRDC Precision；
- PRDC Recall；
- PRDC Coverage；
- Root 内 HSIC；
- 跨窗口标准差；
- 唯一输出数量。

特别比较 F50 与 F0。

F0 是当前最好的迁移生成器，不能因为 F50 的 FR 更高就忽略 F0 原有的分布质量。

## 3. 幅值结构

检查：

- 零比例；
- 正值均值；
- P1/P10/P50/P90/P95/P99；
- 各 Taxel 幅值分布；
- 不同 Root 的幅值差异；
- 响应尾部。

不能通过简单压缩幅值、制造弱响应来换取分类器接受。

## 4. 空间结构

检查：

- 16 Patch 响应分布；
- Patch 激活数量；
- 空间集中程度；
- 局部响应多样性；
- 不同 Root 的空间结构差异。

所有指标沿用既有定义，明确其索引代理性质。

## 5. 时序结构

检查：

- 相邻帧绝对变化；
- 相邻帧相关系数；
- 双方均正值位置的响应变化；
- 连续激活长度；
- 不同 Root 的动态统计。

不能通过输出常量或过度平滑获得表面上的时序稳定。

## 6. 输入依赖和退化负对照

沿用 P49 的：

- Constant；
- RealDonor；
- PairShuffle。

确认新架构不会再次出现：

FR 很高，但输出不依赖原始 Sim 输入的情况。

保留 P49 原有的输入依赖和非退化护栏，不允许重新调整门槛。

# 五、P50 成功与失败判定

本轮采用以下分类：

### A：完整架构改进成功

同时满足：

1. Joint Root Macro FR ≥90%。
2. Real Session Macro Acceptance ≥90%。
3. P49 原有完整质量护栏全部通过。
4. 不出现输入依赖丧失。
5. 不出现明显幅值、空间、时序结构退化。
6. 负对照能够识别退化输出。

这才意味着新架构在当前开发验证范围内实现了有质量约束的迁移。

### B：部分成功

FR 达到90%，但一项或多项质量护栏未通过。

需要具体指出是：

- 幅值问题；
- 空间问题；
- 时序问题；
- 多样性问题；
- 输入依赖问题；
- 分布覆盖问题。

不能宣布完整迁移成功。

### C：架构改进失败

出现以下情况：

- FR 无法达到目标；
- 新判别器存在明显失效；
- 生成器出现严重坍缩；
- Refiner 没有提供有效改善；
- 新架构整体质量比 F0 更差。

保留结果，分析具体原因，不自动开启下一轮。
